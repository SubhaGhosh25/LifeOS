# LifeOS

A practical personal productivity dashboard built with only HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` directly in Chrome, Edge or Firefox.

## Included
- Interactive dashboard
- Tasks with completion state and filters
- Daily routine
- Habits and streaks
- Pomodoro focus timer
- Goals with progress sliders
- Calendar
- Notes
- Journal
- Statistics
- Search
- 7 themes
- Accent colors
- LocalStorage persistence
- JSON backup export
- Responsive/mobile layout

## No Node.js required
This version does not use npm, React, Vite or a build system.

## Important
Data is stored in the browser with localStorage. Different users/devices do not share data yet. A future multi-user version can connect the same UI to a hosted database/auth service such as Supabase.
